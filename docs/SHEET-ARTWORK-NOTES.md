# Approved reference sheet mapping — v0.2.9

v0.2.9 continues using the user-approved **WoD20 Combat Library Interface** screenshot as the source for `portrait-sheet-*.svg` crops. This pass broadens the applied concepts to cover more of the reviewed maneuver folders, especially general maneuvers, dirty fighting, martial arts, Do special techniques and training references.

The module still introduces **no new Items, types or weapon data**. It now assigns **74** existing catalog keys to **41** locally embedded illustrated thumbnail assets from the approved screenshot. Additional non-portrait cleanups use already bundled Game-Icons art where that gives a more accurate match. See `data/icon-map.json` for the exact key mapping.

Existing World Item copies require the usual GM-confirmed, backed-up icon-only refresh if their `img` field is eligible. Actor-owned Items are never rewritten.
